## 1. Установка зависимостей

```bash
pip install numpy pandas matplotlib scikit-learn statsmodels xgboost tensorflow
```

> Если не нужен LSTM — tensorflow можно не ставить;  
> кнопка LSTM просто покажет ошибку с подсказкой.

---

## 2. Запуск

```bash
python weather_forecast_app.py
```

---

## 3. Сборка в .exe (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed weather_forecast_app.py
```

Готовый файл появится в папке `dist/`.

---

## 4. Что делает приложение

| Кнопка | Что происходит |
|---|---|
| **Запустить ARIMA** | Скользящий прогноз ARIMA(5,1,2) на 60 дней |
| **Запустить XGBoost** | Ансамблевая модель, лаговые признаки 14 дней |
| **Запустить LSTM** | Рекуррентная нейросеть, окно 21 день, 30 эпох |
| **Запустить все** | Последовательно все три метода |
| **Очистить** | Сброс графика и метрик |

После запуска на графике отображаются **прогнозы на тестовом окне (60 дней)**,  
внизу левой панели — метрики **MAE / RMSE / MAPE%** по каждому методу.

---

## 5. Данные

Синтетический ряд температуры за 3 года (1095 точек):
- Годовая сезонность (±12 °C)
- Суточный шум (σ = 2 °C)
- Случайные аномалии («волны тепла/холода»)
- Слабый тренд потепления (+0.003 °C/день)
